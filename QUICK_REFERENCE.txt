╔═══════════════════════════════════════════════════════════════════════════╗
║                              METRICS GUIDE                                ║
╚═══════════════════════════════════════════════════════════════════════════╝

  Balance Score = 1 - (σ_util / μ_util)
  ┌───────────────────────────────────────────────────────────────────────┐
  │ 1.0  = Perfect balance (all paths equally utilized)                  │
  │ 0.85 = Target for good load balancing                                │
  │ 0.5  = Moderate imbalance                                            │
  │ 0.0  = Extreme imbalance (all traffic on one path)                   │
  └───────────────────────────────────────────────────────────────────────┘

  Imbalance Factor = max(path_util) / mean(path_util)
  ┌───────────────────────────────────────────────────────────────────────┐
  │ 1.0  = Perfect balance                                               │
  │ 1.3  = Target for acceptable performance                             │
  │ 1.5  = Moderate imbalance (50% difference)                           │
  │ 2.0+ = Severe imbalance (hotspots)                                   │
  └───────────────────────────────────────────────────────────────────────┘

╚═══════════════════════════════════════════════════════════════════════════╝

  Problem: No imbalance observed in ECMP
  Solution: 
    • Increase flow bandwidth: --duration 30
    • Use fewer spines: --spines 2
    • Verify port collision patterns are active

  Problem: Mininet cleanup fails
  Solution:
    sudo mn -c
    sudo systemctl restart openvswitch-switch

  Problem: iperf3 connection refused
  Solution:
    • Check servers started (look for "Server started" messages)
    • Increase server startup delay in code
    • Verify firewall not blocking ports 5000-6000

  Problem: No packet drops despite oversubscription
  Solution:
    • Increase test duration: --duration 30
    • Reduce buffer size in topology (edit leaf_spine.py)
    • Increase flow bandwidth in test code
